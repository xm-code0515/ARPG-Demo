# 开始界面与游戏菜单

`Assets/Game/Prefabs/UI/ModernGameMenu.prefab` 使用 SlimUI Modern Menu 1 的按钮 Prefab、正常/悬停/按下图案、装饰、面板边框和音效。界面为可在 Unity 编辑的屏幕叠加 uGUI；开始界面背景来自当前森林地图的静态画面，不额外加载地图或运行菜单摄像机。

- 开始界面：大标题 ARPG DEMO，单人游戏、多人游戏、退出游戏；无重复小标题与左下角标语。
- 多人页面：创建互联网房间、输入加入码、加入房间、返回。继续调用现有 GameSessionController / OnlineRoomService。
- 启动、加载、返回与失败状态显示中文提示；失败可返回主界面。
- 游戏内按 Esc 打开居中的游戏菜单；继续游戏或再次 Esc 关闭，返回主界面正常关闭当前会话。
- 在线房间额外显示加入码及复制按钮，房主显示关闭房间的提示。
- 菜单打开时阻止本地移动、攻击、视角、交互和背包切换；关闭后恢复输入。背包、NPC 对话或任务界面打开时，Esc 先关闭对应界面，游戏菜单不同时弹出。
- 菜单按钮与提示为中文，游戏标题为 ARPG DEMO；复用项目现有的微软雅黑动态字体方式。与当前其他中文 UI 一样，部署到其他平台时需要准备对应的字体资源。

视图 `Game.Presentation.UI.ModernMenuView` 只负责显示和按钮事件；`Game.Network.GameMainMenu` 负责把事件连接到会话控制器。`NetworkPlayerItemsUIBinder` 汇总菜单、背包、任务和对话的输入阻止状态。SlimUI 原包保持完整，原包的示例场景切换、示例画质设置脚本没有接入游戏菜单。

验证：单人两次进入/返回、按钮点击接线、悬停图案切换、输入阻止与恢复、菜单期间背包切换阻止、背包正常阻止/恢复输入均已检查，运行时菜单及 EventSystem 各一份。未重测互联网创建/加入和双人联机。编辑器游戏窗口未取得输入焦点，因此真实 Esc 按键测试未完成；模拟按键在失焦时正确被忽略。验证记录位于 Logs/ModernMenu/Validation.json。
