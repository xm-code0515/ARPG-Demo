# 快捷栏

左上角 8 格是额外存储，背包保留原有容量。打开背包后可拖拽物品进出快捷栏、交换、Shift 拆分、丢弃和悬停查看属性。拾取时先补快捷栏同种堆叠，再填快捷栏空格，然后使用背包同种堆叠和空格。材料也可以放入快捷栏。

正常操控时按主键盘 1～8：武器直接装备，食物消耗 1 个，材料无使用动作。装备中的快捷栏武器留在原格并高亮，再按相同数字键可卸下；另一把武器的数字键可换装。移走或丢弃当前快捷栏武器会卸下。原有主手格仍可使用，不复制武器。攻击和翻滚期间不能换装。

`Assets/Game/Prefabs/UI/PlayerHotbarHUD.prefab` 是 PlayerHUD 下的独立 uGUI prefab。根 RectTransform 调位置，Slot1～8 的 Icon、Name、Quantity、Key 和 Equipped 控制图标、名称、数量、数字和选中底色。运行时仅绑定数据。子 Canvas 排序 110，背包为 100，确保打开背包仍能拖入快捷栏。

NetworkInventory 的网络列表先存背包，最后 8 项存快捷栏。对外背包地址为 0～capacity-1，快捷栏为 100～107，主手为 -2。Owner RPC 校验物品与数量，Host 处理装备和食用。快捷栏装备引用实际格子，主手显示的是同一物品；普通背包装备继续独立存放主手。修改物品移动或丢弃时，注意区分这两种所有权，避免重复或丢失。

食品使用 RPC 独立于拖拽操作确认，没有食用冷却；连续点击不同食物不必等上一种食物确认。食品同种刷新规则见 README_Food。Host 和 Client 使用相同新版代码与目录，旧构建需重新打包。
